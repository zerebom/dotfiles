# リライト完了チェックリスト

修正完了時に以下を確認する。

---

## 1. 構造チェック

- [ ] セクション間で役割が重複していないか
- [ ] 同じ内容を別セクションで繰り返していないか
- [ ] 「目的」と「結論/リリース計画」が論理的につながっているか

---

## 2. 分量チェック

- [ ] 各パラグラフは3文以内か
- [ ] 「背景」「目的」等は3〜5文で要点が伝わるか
- [ ] 同じ主張を言い換えて繰り返していないか
- [ ] 「〜することで、〜を実現し、〜を可能にする」のような目的語の連続がないか

---

## 3. 修飾語チェック

以下の修飾語が数字・具体例なしで使われていないか：

- [ ] 「非常に」
- [ ] 「極めて」
- [ ] 「大きな」
- [ ] 「高い」
- [ ] 「強力な」
- [ ] 「効果的な」

---

## 4. 太字チェック

- [ ] 1セクションあたり太字は3〜5箇所以内か
- [ ] 太字はKPI/決定事項/制約に限定されているか
- [ ] 一般名詞・形容詞を装飾目的で太字にしていないか
- [ ] 文章全体の1〜2割以上が太字になっていないか

---

## 5. AI表現チェック

以下のフレーズが残っていないか：

- [ ] 「〜と言える」
- [ ] 「〜と考えられる」
- [ ] 「〜が想定される」
- [ ] 「〜が期待される」
- [ ] 「〜に寄与する」

残っている場合、事実ベース・主語明確な文に書き換える。

---

## 6. 箇条書きチェック

- [ ] 箇条書き1つは1行以内（長くても2行）か
- [ ] 列挙が多い箇所は箇条書きになっているか

---

## 7. 検討事項チェック

- [ ] 未決定事項は「Open Questions」「要検討事項」に明記されているか
- [ ] 決定事項と検討中事項が混在していないか

---

## 8. トーンチェック

- [ ] 「だ・である調」で統一されているか
- [ ] 過度に堅くなっていないか
