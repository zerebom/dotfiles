# 万能フレーム抽出 - Speaking Output Trainer

暗記した英文（Input）を実際の会話で使える運用語彙（Output）に変換するためのトレーニング表を作成する。

## 背景（SLA理論）

第二言語習得において、インプットした知識を実際のアウトプットで使えるようにするには「構文の骨組み（フレーム）」を抽出し、様々な文脈で使い回す練習が効果的。このスキルはその練習素材を自動生成する。

## ワークフロー

### Step 1: 入力解析

ユーザーの入力テキストを解析する：
- 表形式（日本語 | 英語 | 発音記号）
- 解説付きテキスト
- 生の英文リスト

セクションタイトル（例：`## P143 53 副詞のカタマリをつくる接続詞`）があれば識別する。

### Step 2: フレームスキャン

入力テキストから汎用性の高い文法構造を探す：

**抽出対象：**
- S+Vのパターン（I think..., I wonder if..., It seems that...）
- 接続詞パターン（when..., if..., although..., unless...）
- 便利な導入句（The point is..., What I mean is...）
- 使役・知覚構文（make/let/have + O + V, see/hear + O + V）
- 仮定法パターン（If I were..., I wish...）

**除外対象：**
- 固有名詞・専門用語に依存する表現
- 一度しか使わない慣用句
- 文脈依存が強すぎる表現
- ニュース・プレスリリース・フォーマル文書特有の堅い表現（日常会話で大げさ・不自然に聞こえるもの）

### Step 3: 抽象化

各文の「言いたいこと（機能）」を残し、具体的な単語を取り払って「フレーム」にする：

例：
- "I want to check if your company can repave the road."
  → フレーム: **I want to check if...**
- "Although I have never lived abroad, I can speak English."
  → フレーム: **Although..., S + V**

### Step 4: 選抜・優先順位付け

以下の基準で優先順位をつけ、入力量に応じて抽出：
- 短い入力（〜10文）: 3〜5個
- 中程度（10〜30文）: 5〜10個
- 大量入力（30文〜）: 10〜15個

**優先度（高→低）：**
1. 日常会話（雑談・友人との会話）で自然に使える
2. 社内コミュニケーション（同僚との会話・チャット・カジュアルなメール）で使える
3. 独り言・思考整理で使いやすい
4. シンプルで覚えやすい構造

※ニュース・プレゼン・フォーマル文書でしか使わない表現は除外する

### Step 5: 入れ替え例生成

各フレームに対し、3つのシーン別入れ替え例を作成：

- **💬 雑談**: 友人・家族との日常会話で使う例
- **💼 仕事**: 社内ミーティング・同僚との会話で使う例
- **🧠 独り言**: 思考整理・セルフトークで使う例

**ルール：**
- 中学英語レベルの単語を使用
- 実際に口に出しやすい自然な文
- 各シーンで本当に使いそうな具体的な状況

### Step 6: 表生成

以下のマークダウン表形式で出力（1フレームにつき3行に分ける）：

```markdown
## [セクションタイトル] - 万能フレーム集

| 💭 日本語ニュアンス | 🔧 万能フレーム | 📦 入れ替え例 | 📝 元テキスト |
| :--- | :--- | :--- | :--- |
| 〜かどうか確認したい | **I want to check if...** | 💬 I want to check if this is okay. | I want to check if your company can... |
| | | 💼 I want to check if the meeting is still on. | |
| | | 🧠 I want to check if I locked the door. | |
```

**重要**: `<br>` タグは使用しない。入れ替え例は3行に分けて出力する。

### Step 7: クリップボードにコピー

表生成完了後、最終出力をクリップボードにコピー：

```bash
echo "生成したマークダウン表" | pbcopy
```

コピー完了を通知する。

## 出力フォーマット

```markdown
## [セクションタイトル] - 万能フレーム集

| 💭 日本語ニュアンス | 🔧 万能フレーム | 📦 入れ替え例 | 📝 元テキスト |
| :--- | :--- | :--- | :--- |
| (機能を日本語で) | **フレーム** | 💬 雑談例 | (該当する元の英文) |
| | | 💼 仕事例 | |
| | | 🧠 独り言例 | |
```

## ルール

- マークダウン表のみ出力（説明文・挨拶は最小限）
- 発音記号は不要
- 重複するフレームは統合（最も良い元テキストを引用）
- 頻出度・汎用性が高い順に並べる
- 入れ替え例は実際に使いそうな具体的な文にする
- 複数セクションがある場合は個別に表を作成

## 出力例

入力：
```
| 日本語 | 英語 |
| --- | --- |
| ★(1-4) ～だけれども　私は外国に1度も住んだことがない、私は英語が話せます | Although I have never lived abroad, I can speak English. |
| (2-3) もしあなたが早めに来たら、あなたは～を飲めます　無料のコーヒーを | If you come early, you can drink free coffee. |
```

出力：
```markdown
## 副詞のカタマリをつくる接続詞 - 万能フレーム集

| 💭 日本語ニュアンス | 🔧 万能フレーム | 📦 入れ替え例 | 📝 元テキスト |
| :--- | :--- | :--- | :--- |
| 〜だけれども（逆接・譲歩） | **Although..., S + V** | 💬 Although it's raining, let's go out. | Although I have never lived abroad, I can speak English. |
| | | 💼 Although I'm busy, I can join the meeting. | |
| | | 🧠 Although I'm tired, I should finish this. | |
| もし〜なら（条件） | **If you..., you can...** | 💬 If you want, you can come with me. | If you come early, you can drink free coffee. |
| | | 💼 If you need help, you can ask me. | |
| | | 🧠 If I wake up early, I can exercise. | |
```
