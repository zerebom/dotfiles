# テンプレート集

このファイルは「きれいな資料を作るため」ではなく、
**問う → 見る → 考える → 決める** を漏れなく進めるための「型」を定義することを目的とする。
必要に応じて削ってよく、すべてを機械的に埋める必要はない。

## 分析レポートテンプレート

最終成果物として出力するレポートの構造。**基本はこれに沿うが、ケースに応じて大胆に削ってよい。**

```markdown
# [分析タイトル]

作成日: YYYY-MM-DD
作成者: [名前/チーム名]
対象期間: YYYY-MM-DD 〜 YYYY-MM-DD

---

## エグゼクティブサマリー

[3〜6 行で、以下の 3 点を必ず含めて要約する]
- 何がわかったか（結論）
- なぜ重要か（インパクト）
- 次に何をすべきか（アクション）

---

## 1. 背景と目的

### 1.1 背景

[なぜこの分析が必要になったのか、ビジネス上の文脈を 2〜3 文で記載]

### 1.2 分析目的

本分析では以下の問いに答えることを目的とする：

1. [問い1]
2. [問い2]
3. [問い3]

### 1.3 想定読者

- [想定読者1: 例）経営層]
- [想定読者2: 例）プロダクトマネージャー]

---

## 2. データ概要

### 2.1 データソース

| 項目 | 内容 |
|------|------|
| データ元 | [システム名/DB名/ファイル名] |
| 取得日 | YYYY-MM-DD |
| 対象期間 | YYYY-MM-DD 〜 YYYY-MM-DD |
| レコード数 | X,XXX件 |

### 2.2 主要カラム

| カラム名 | 説明 | 型 |
|----------|------|-----|
| [カラム1] | [説明] | [数値/カテゴリ/日付] |
| [カラム2] | [説明] | [数値/カテゴリ/日付] |

### 2.3 データ品質

- 欠損値: [カラム名に X% の欠損あり。除外/補完で対応]
- 外れ値: [カラム名に X件の外れ値あり。クリップ/除外で対応]
- その他: [エンコード問題など]

### 4.1 ビジネスインパクト

| 発見 | インパクト | 影響範囲 |
|------|----------|----------|
```

## 分析ブリーフテンプレート

分析開始前にユーザーと合意する内容をまとめるテンプレート。ここでサボると、後ろが全部ブレる。

```markdown
## 分析ブリーフ

### 基本情報

| 項目 | 内容 |
|------|------|
| 分析名 | [分析の名称] |
| 依頼者 | [依頼者名] |
| 作成日 | YYYY-MM-DD |
| 期限 | YYYY-MM-DD |

### 背景

[このサービス・事業の概要と、現状の課題を 2〜4 文で記載]

### 解きたい問い

1. **[問い1]**
   - 背景: [なぜこの問いが重要か]
   - 失敗パターン: [この問いに答えないと、どんな誤った意思決定が起こりうるか]
   - 期待するアウトプット: [どんな形式の答えがほしいか]

2. **[問い2]**
   - 背景: [...]
   - 期待するアウトプット: [...]

### 想定読者・意思決定者

| 読者 | 関心事項 | 求める粒度 |
|------|----------|----------|
| [経営層] | [全体傾向、インパクト] | [サマリーレベル] |
| [PdM] | [機能別の詳細、優先度] | [詳細レベル] |

### 時間軸

- [ ] 過去分析（何が起きたか）
- [ ] 現状把握（今どうなっているか）
- [ ] 将来予測（これからどうなるか）

### 制約

| 制約種別 | 内容 |
|----------|------|
| データ範囲 | [利用可能なデータの期間・範囲] |
| 時間制約 | [分析に使える時間] |
| 技術的制約 | [使用可能なツール・環境] |
| その他 | [その他の制約事項] |

### 合意事項

- [ ] 上記内容でブリーフを確定
- [ ] 分析プラン作成に進む
```

## 仮説メモテンプレート

分析中に立てた仮説を記録・検証するためのテンプレート。"なんとなくそう見える" を一段具体化するために使う。

```markdown
## 仮説メモ

### 仮説一覧

| ID | 仮説 | 根拠 | 検証方法 | 結果 | ステータス |
|----|------|------|----------|------|-----------|
| H1 | [仮説の内容] | [仮説を立てた根拠] | [どう検証するか] | [検証結果] | 未検証/支持/棄却 |
| H2 | [仮説の内容] | [仮説を立てた根拠] | [どう検証するか] | [検証結果] | 未検証/支持/棄却 |

### 仮説詳細

#### H1: [仮説タイトル]

**仮説**: [仮説の内容を1文で]

**根拠**:
- [この仮説を立てた理由1]
- [この仮説を立てた理由2]

**検証方法**:
- データ: [使用するデータ]
- 手法: [使用する分析手法]
- 判定基準: [どうなれば仮説を支持/棄却するか]

**検証結果**:
- [検証で得られた結果]
- [データ・グラフ等のエビデンス]

**結論**: [支持/棄却] - [理由]
```

## ミニチェックリスト

分析が薄くならないための、Claude 向け・人間向け共通チェックリスト。

- **問いのレベル**
  - [ ] "売上が落ちた理由" のような大きすぎる問いを、そのまま扱っていないか？
  - [ ] 「誰の・どの期間・どの指標か」まで絞れているか？
- **事実と解釈**
  - [ ] グラフや数字の説明だけで終わっていないか？
  - [ ] "だから何か" が 1 文以上で書かれているか？
- **アクション**
  - [ ] 「やること」だけでなく「やめること」も検討したか？
  - [ ] 誰がいつまでに動くのか、イメージできる粒度になっているか？

このテンプレート集はあくまで出発点であり、プロジェクトごとに上書きして構わない。
