# 座標計画テンプレート

このテンプレートは、スイムレーン図を作成する前にエンティティの配置を計画するためのものです。

## 目的

- エンティティの座標を事前に計画し、重複を防ぐ
- 適切なスペーシングを確保する
- ユーザーに視覚的なレイアウトを提示し、承認を得る

## キャンバスサイズ計算

### 計算式

- **幅** = 120 (左マージン) + (ステップ数 × 200) + 120 (右マージン)
- **高さ** = 120 (上マージン) + (アクター数 × 160) + 40 (下マージン)

### 例

3アクター、5ステップのプロセスの場合：
- 幅 = 120 + (5 × 200) + 120 = 1240px
- 高さ = 120 + (3 × 160) + 40 = 640px

## スイムレーンレイアウト（Y軸）

各スイムレーンは水平に配置され、1つのアクター（人、部門、またはシステム）を表します。

### テンプレート

| アクター名 | Y開始 | Y終了 | 高さ | 色 |
|-----------|-------|-------|------|-----|
| {actor1} | 120 | 280 | 160 | 青 (#dae8fc) |
| {actor2} | 280 | 440 | 160 | 緑 (#d5e8d4) |
| {actor3} | 440 | 600 | 160 | オレンジ (#ffe6cc) |

### 計算ルール

- 最初のレーンのY開始 = 120（上マージン）
- 各レーンの高さ = 160px（固定）
- 次のレーンのY開始 = 前のレーンのY終了

## エンティティ位置（X軸: 時間進行）

X軸は左から右へ時間が進行します。

### エンティティタイプと標準サイズ

| タイプ | 形状 | 標準幅 | 標準高さ | 用途 |
|--------|------|--------|----------|------|
| start/end | 楕円 | 80-100 | 60 | プロセスの開始・終了 |
| task | 角丸矩形 | 120-200 | 80 | アクティビティ・タスク |
| decision | ひし形 | 100-140 | 100 | 判断・分岐点 |

### テキスト幅計算

日本語テキストの場合：
- **1文字あたり30-40px**を目安とする
- 例: 「問い合わせ受信」(7文字) = 7 × 35 = 245px
- 余裕を持って +20px 程度追加

### X座標計算ルール

- 最初のエンティティ: X = 160（左マージン + 40）
- 次のエンティティ: X = 前のエンティティのX + 前の幅 + 最小ギャップ（120px）
- 例: 320 = 160 + 80 + 80（調整）

## スペーシング検証

以下の最小スペーシング要件を満たす必要があります。

### 必須スペーシング

| 項目 | 最小値 | 説明 |
|------|--------|------|
| 水平ギャップ | 120px | エンティティ間の左右の間隔 |
| 垂直マージン | 40px | スイムレーン境界からの上下の余白 |
| 矢印ラベルクリアランス | 40px | 矢印ラインからラベルまでの距離 |

### 検証チェックリスト

- [ ] すべてのエンティティ間の水平ギャップが120px以上
- [ ] すべてのエンティティがレーン境界から40px以上離れている
- [ ] テキストが適切な幅に収まっている（1文字30-40px）
- [ ] 矢印ラベルが矢印から40px以上離れている
- [ ] エンティティ同士が重複していない

## 視覚的ASCIIマップ

エンティティの配置を視覚的に表現します。

### テンプレート

```
=== 座標計画: {プロセス名} ===

キャンバス: {width}px × {height}px

┌────────────────────────────────────────────────────────────┐
│ {Actor1 名}                                                │
│   [開始]──→[タスク1]──→[判断]                            │
│                           ↓                                │
├─────────────────────────┼─────────────────────────────────┤
│ {Actor2 名}             ↓                                  │
│                      [タスク2]──→[タスク3]               │
│                                     ↓                      │
├─────────────────────────────────────┼─────────────────────┤
│ {Actor3 名}                         ↓                      │
│                                  [終了]                    │
└────────────────────────────────────────────────────────────┘

スペーシング検証: ✓ すべてクリア
```

### 記号の凡例

- `[要素名]`: エンティティ（開始/終了、タスク、判断）
- `──→`: 矢印（左から右）
- `↓`: 矢印（上から下）
- `├─┼─┤`: レーン境界

## ユーザー確認プロンプト

座標計画を提示した後、以下のようにユーザー確認を取得します。

```
=== 座標計画の確認 ===

上記のレイアウトで進めますか？

選択肢:
1. yes - このレイアウトで進める
2. no - レイアウトを修正する（具体的な修正内容を教えてください）
3. modify - 特定の要素を調整する

ご回答:
```

## 実装時の注意事項

1. **バウンディングボックス計算**: エンティティの幅は、テキスト長に基づいて動的に計算する
2. **重複検出**: X座標とY座標の両方で重複をチェックする
3. **レーン境界**: エンティティがレーン境界を超えないよう検証する
4. **矢印のルーティング**: 矢印が他のエンティティを通過しないよう配慮する

## トラブルシューティング

### 問題: エンティティが重複している

**原因**: 水平ギャップが120px未満
**解決策**: X座標を調整し、最小ギャップを確保

### 問題: テキストが改行される

**原因**: エンティティの幅が不足
**解決策**: テキスト長 × 35px + 20px の幅を確保

### 問題: エンティティがレーン外に出る

**原因**: Y座標がレーン境界を超えている
**解決策**: レーン境界から40px以上のマージンを確保
