# スイムレーン図検証チェックリスト

ユーザーに図を提示する前に、このチェックリストを使用してください。

**重要**: XML構造が正しくても、PNGで見ると問題があるケースが多い。**必ずPNG画像を目視で確認**すること。

## 🔍 視覚品質チェック

### ✅ テキストの読みやすさ
- [ ] **すべてのテキストが可視**: 白背景に白テキストがないこと
- [ ] **フォント色が設定済み**: すべてのテキスト要素のstyleに `fontColor=#000000;` が含まれている
- [ ] **フォントファミリーが設定済み**: すべてのテキスト要素のstyleに `fontFamily=Noto Sans JP;` が含まれている
- [ ] **フォントサイズが十分**: すべてのテキストが `fontSize=18` 以上を使用
- [ ] **意図しない改行がない**: 日本語テキストに十分な幅がある（1文字あたり30-40px）

### ✅ レイアウトと構造
- [ ] **X軸は時間**: プロセスが左から右に流れている
- [ ] **Y軸はアクター**: 水平方向のスイムレーンがアクター/部門を表している
- [ ] **スイムレーンラベルが明確**: アクター名が見え、左端に配置されている
- [ ] **要素の重なりがない**: すべてのボックス、矢印、ラベルに十分な間隔がある
- [ ] **スイムレーンの境界が正しい**: すべての要素がそれぞれのスイムレーン内にある
- [ ] **プロセスの完結性**: すべてのレーンのフローが開始から終了まで追跡可能

### ✅ 矢印の接続
- [ ] **矢印がボックスに接続**: すべての矢印が `source="id" target="id"` を使用（浮遊していない）
- [ ] **矢印ラベルが明確**: ラベルが矢印の線と重なっていない（40px以上の間隔）
- [ ] **矢印の方向が正しい**: フローが時系列と一致（左から右）

### ✅ 矢印のルーティング品質（PNG目視必須）

**このカテゴリはPNG画像を見て判断すること。XML構造だけでは判断できない。**

- [ ] **矢印同士が交差していない**: 矢印の経路が他の矢印と重なったり交差していないこと。PNG上で矢印が×印のように交差していたらFAIL
- [ ] **矢印の密集がない**: 1つのノードに3本以上の矢印が集中していないこと。集中している場合、レイアウトの再配置が必要
- [ ] **クロスレーン矢印が明快**: レーンをまたぐ矢印は、可能な限り垂直（真下/真上）に配置されていること。斜めに2レーン以上横断する矢印はFAIL
- [ ] **矢印がノードやラベルを通過していない**: 矢印の経路が他のボックスやテキストの上を通過していないこと
- [ ] **矢印のルートが自然**: orthogonalEdgeStyleの自動ルーティングで不自然な迂回や折り返しが発生していないこと

### ✅ 座標ベース検証（drawio XMLから算出）

**drawio XMLを読み、エンティティの絶対座標を計算して検証すること。**

計算方法: 要素の絶対座標 = レーンのXY + 要素のrelativeXY

- [ ] **水平ギャップ≧120px**: 同一レーン内の隣接エンティティ間の水平距離が120px以上
- [ ] **垂直マージン≧40px**: エンティティがレーン境界（上端/下端）から40px以上離れている
- [ ] **クロスレーン矢印の垂直整列**: source要素とtarget要素のX中心座標の差が50px以内であること（垂直に近い矢印になる）
- [ ] **分岐元ノードの出力数≦3**: 1つのノードから出る矢印が3本以下。4本以上ある場合はノードの統合や中間ノードの追加を検討

### ✅ BPMN記号
- [ ] **開始/終了が楕円**: プロセスの開始と終了に `ellipse` スタイルを使用
- [ ] **アクティビティが角丸四角形**: タスクに `rounded=1; arcSize=10` を使用
- [ ] **判断がひし形**: 判断ポイントに `rhombus` スタイルを使用（該当する場合）

## 🔧 技術的検証

### ✅ XML構造
- [ ] **親属性が設定済み**: すべてのスイムレーンの子要素に `parent="laneX"` がある
- [ ] **矢印がsource/targetを使用**: 座標ベースの矢印がない
- [ ] **一意なID**: すべての要素に一意な `id` 属性がある
- [ ] **デフォルトフォントファミリー**: `<mxGraphModel>` に `defaultFontFamily="Noto Sans JP"` がある

### ✅ ファイル出力
- [ ] **PNGファイルが存在**: `convert_to_png.sh` を使用してPNGに変換済み
- [ ] **正しいファイル名**: PNGが `diagram.png` という名前（`diagram.drawio.png` ではない）
- [ ] **PNGが読める**: PNGファイルを開いて視覚的に確認済み
- [ ] **白背景**: 背景が白色（透過ではない）

## 🚨 避けるべき一般的なミス

- ❌ `fontColor` がない白いボックス → テキストが見えない
- ❌ `<mxPoint>` 座標を使った矢印 → 浮遊する矢印
- ❌ `parent="laneX"` の欠落 → 要素がスイムレーンの外に出る
- ❌ PNG確認をスキップ → 未確認の図を提示
- ❌ ラベルと矢印の重なり → 乱雑なレイアウト
- ❌ **矢印の交差・密集を見落とす** → XML構造だけでPASSにしてはいけない。必ずPNGを目視確認
- ❌ **1ノードから4本以上の分岐** → 読みづらいので中間ノードで分散させる
- ❌ **斜めに2レーン以上を横断する矢印** → 出力ノードをターゲットの真上に配置して垂直に落とす

## ✅ 最終承認

上記のすべての項目を確認した後のみ:
- [ ] **セルフレビュー完了**: すべてのチェックリスト項目が合格
- [ ] **ユーザーレビュー準備完了**: 図をユーザーに提示できる

---

**注意**: いずれかの項目が不合格の場合、`.drawio` ファイルを修正し、PNG に再変換して、全リストを再確認してください。
