# スイムレーン図サンプル

このサンプルは swimlane-diagram スキルの期待される出力を示しています。

## サンプル: シンプル線形フロー

- **ファイル**: `simple-linear-flow.drawio`, `simple-linear-flow.png`
- **目的**: 基本的なスイムレーン構造のデモンストレーション
- **プロセス**: 顧客問い合わせ対応プロセス
- **タイプ**: As-Is（現状プロセス）

### プロセスの特徴

**アクター（3つ）**:
- **顧客（Customer）**: 問い合わせを送信し、回答を受け取る
- **サポート（Support）**: 問い合わせを受信し、顧客に回答を送信する
- **エンジニアリング（Engineering）**: 技術調査と回答作成を行う

**フロー**:
1. 顧客: 問い合わせを送信（開始イベント）
2. サポート: 問い合わせを受信
3. サポート: 内容を確認
4. エンジニアリング: 技術調査を実施
5. エンジニアリング: 回答を作成
6. サポート: 顧客に回答を送信
7. 顧客: 回答を受信（終了イベント）

### 技術仕様

このサンプルは以下のすべての品質基準を満たしています：

**視覚品質**:
- ✓ すべてのテキストが黒字（`fontColor=#000000`）
- ✓ すべてのテキストが Noto Sans JP フォント
- ✓ すべてのテキストが 18px 以上のフォントサイズ
- ✓ 白背景（透過ではない）
- ✓ 意図しない改行なし

**レイアウトと構造**:
- ✓ X軸が時間進行（左から右）
- ✓ Y軸がアクター（水平スイムレーン）
- ✓ スイムレーンの色が区別されている
- ✓ すべての要素がスイムレーン境界内

**矢印の接続**:
- ✓ すべての矢印が `source/target` 属性で接続
- ✓ 矢印ラベルが矢印から40px以上離れている
- ✓ 部門横断的な矢印が正しく接続されている

**BPMNシンボル**:
- ✓ 開始/終了が楕円形（`ellipse`）
- ✓ アクティビティが角丸矩形（`rounded=1; arcSize=10`）

**スペーシング**:
- ✓ エンティティ間の水平ギャップが120px以上
- ✓ レーン境界からの垂直マージンが40px以上

### スイムレーンの色設定

| アクター | fillColor | strokeColor | 色の印象 |
|---------|-----------|-------------|---------|
| 顧客 | #dae8fc | #6c8ebf | 青系 |
| サポート | #d5e8d4 | #82b366 | 緑系 |
| エンジニアリング | #ffe6cc | #d79b00 | オレンジ系 |

これらの色は視覚的に区別しやすく、印刷時にも判読可能です。

## 使用方法

### 1. 参照テンプレートとして使用

新しいスイムレーン図を作成する際、このサンプルを参照してください：

```bash
# サンプルをコピーして新しい図を作成
cp references/samples/simple-linear-flow.drawio my-process.drawio
```

### 2. 品質基準の確認

自分の図が以下の品質基準を満たしているか確認してください：

- すべてのテキストが読める（黒字、白背景）
- 矢印が正しく接続されている（浮遊していない）
- スイムレーンが明確に区別されている
- X軸が時間進行、Y軸がアクターを表している
- BPMNシンボルが正しく使用されている

### 3. PNG確認

サンプルのPNGを開いて、期待される視覚的品質を確認してください：

```bash
open references/samples/simple-linear-flow.png
```

### 4. XML構造の学習

drawioファイルをテキストエディタで開き、正しいXML構造を学習してください：

```bash
# テキストエディタで開く
code references/samples/simple-linear-flow.drawio
```

**学習ポイント**:
- `<mxGraphModel>` の `defaultFontFamily` 設定
- `<mxCell>` の `style` 属性の構造
- `parent="laneX"` による親子関係
- `source="id1" target="id2"` による矢印接続

## サンプルの生成方法

このサンプルは以下の手順で作成されました：

1. **座標計画**: エンティティの位置を事前に計画
2. **XML生成**: `assets/swimlane_template.drawio` をベースに手動作成
3. **PNG変換**: `bash scripts/convert_to_png.sh simple-linear-flow.drawio`
4. **検証**: `references/checklist.md` の43項目すべてをチェック
5. **修正**: 不合格項目を修正し、再度PNG変換・検証

## トラブルシューティング

### 問題: テキストが見えない

**原因**: `fontColor=#000000` が設定されていない
**解決策**: すべてのテキスト要素の `style` 属性に `fontColor=#000000;` を追加

### 問題: 矢印が浮遊している

**原因**: 座標ベースの矢印（`<mxPoint>`）を使用している
**解決策**: `source="elementId" target="elementId"` 属性を使用

### 問題: エンティティがスイムレーンの外に出る

**原因**: `parent="laneX"` 属性が設定されていない
**解決策**: スイムレーン内のすべての要素に `parent="laneX"` を追加

### 問題: PNG背景が透過になっている

**原因**: `convert_to_png.sh` で `-t` フラグを使用している
**解決策**: `-t` を `-b white` に変更
